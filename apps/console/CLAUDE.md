# apps/console

The Vertex staff console (ADR 0002, layout ADR 0020): a React + Vite + TanStack Router app, browser only, Arabic-first RTL (ADR 0018). Copied from Vertex Shifa's console skeleton and adapted. Today it is the shell only: no API calls or sign-in yet. S20 brings the dispatch board; S22 restaurants, agreements, entitlements and support access.

## Layout
- `src/main.tsx` mounts the router and i18n; `src/routes/` holds thin file-based routes (TanStack Router; `src/routeTree.gen.ts` is generated by the Vite plugin on `dev` and `build`, committed, never edited or read); `__root.tsx` sets the shell and the error and not-found states.
- `src/features/<area>/`: the components, queries and forms of one area; the pattern to copy is `features/home/`. App-wide `src/components/` (shell, states) and `src/lib/` (`i18n.ts`; `error-logging.ts`: errors logged by name only).
- `src/styles.css`: local colors (light and dark) and spacing until the brand phase replaces them with `packages/tokens` and `packages/ui`. The shell, states, styles and source tests copy the `apps/restaurant` renderer and move to `packages/ui` with the design system.
- `test/`: source tests (`logical-css.test.ts`). Unit tests sit next to the code. `e2e/`: Playwright against `vite preview`, light and dark.
- Ports: dev 5274, `vite preview` 4274.

## Rules
- Every text through i18next with keys from `packages/i18n` (this app's namespace is `console`); never a literal in a component. Numbers and dates through `Intl` with `formatLocale` from `@vertex-food/i18n` (Latin digits); times shown in `Asia/Damascus`.
- Logical CSS only, pinned by `test/logical-css.test.ts`, as in `apps/restaurant`.
- Every screen has its loading, empty, error and offline states (ADR 0020). An error state never shows or logs the error's message (ADR 0016); log errors with `logErrorLabel`.
- The console calls only `/api/console/` routes, which declare `@ConsoleRoute(permission)`; UI checks are cosmetic (ADR 0005).
- No `X-Powered-By`; security headers (CSP and the rest) are set by the host at the first deploy.
- UI changes add or update the E2E RTL screenshots (light and dark) and are looked at before the PR.

Run: `pnpm --filter @vertex-food/console test` · E2E (after `build`): `pnpm --filter @vertex-food/console test:e2e` · dev: `pnpm --filter @vertex-food/console dev`.
