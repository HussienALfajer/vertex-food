# apps/driver

Vertex Food Driver, for restaurant and Vertex drivers (ADR 0003, 0009, 0024, layout ADR 0020): React Native + Expo (SDK 58, managed workflow, prebuild when a native module needs it) with Expo Router, Android first, Arabic-first RTL (ADR 0018). Copied from `apps/customer`. Today it is the shell only. S19 brings duty, jobs, the foreground-service tracker, the SQLite queue with its time base and the outcomes screen (ADR 0024).

## Layout
- `app.config.ts`: the app name from the catalog (`driver.appName`), Android only, RTL forced natively (`extra.forcesRTL`), the sitemap route off. Store identifiers, the EAS project and icons arrive with the first store build (Q3). `android/` is generated by prebuild and git-ignored.
- `src/app/`, `src/features/<area>/`, `src/components/`, `src/lib/`, `test/`: as in `apps/customer`; the pattern to copy is `features/home/`.
- `pnpm build` is `expo export` for Android (the JavaScript bundle, into `dist/`); native builds run on EAS Build or a CI runner outside Syria, because Google's SDK downloads fail from there (ADR 0024). Dev server: 5277.

## Rules
- Every text through i18next with keys from `packages/i18n` (this app's namespace is `driver`); never a literal in a component. Latin digits through `formatLocale`; times shown in `Asia/Damascus`.
- Logical style properties only, pinned by `test/logical-styles.test.ts`; colors through `useColors()`; as in `apps/customer`.
- Location only while on duty, through a foreground service the driver starts from the screen; no background location permission; `RECEIVE_BOOT_COMPLETED` declared with `expo-location` (ADR 0024). A driver sees customer details only while the job is active (ADR 0009).
- Customer phones, addresses and driver locations travel only in request and response bodies, never in URLs or logs (ADR 0006, 0016). Requests use a native timeout, never `fetch` with a JavaScript timer (ADR 0024).
- Every screen has its loading, empty, error and offline states (ADR 0020); queued job events and their outcomes are always visible, never dropped silently (ADR 0024). An error state never shows or logs the error's message; log errors with `logErrorLabel`.
- Versions of Expo packages come from `pnpm exec expo install <package>`, pinned exactly; ADR 0024 lists the S19 additions.
- No RTL screenshot yet: the app has no web export. Screens are checked on a development build or a real phone (Q19).

Run: `pnpm --filter @vertex-food/driver test` · build: `pnpm --filter @vertex-food/driver build` · dev: `pnpm --filter @vertex-food/driver dev`.
